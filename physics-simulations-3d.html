Equations
Hall Voltage
V_H = IB / (nqt)
Transverse voltage developed when current-carrying conductor sits in a perpendicular B field.
I = current (A)
B = magnetic flux density (T)
n = charge carrier density (m⁻³)
t = conductor thickness (m)
Lorentz + Electric Balance
qE_H = qv_d B
Equilibrium when the Hall electric field force exactly balances the magnetic Lorentz force on carriers.
Hall Coefficient
R_H = 1 / (nq)
Positive for p-type semiconductors (hole carriers), negative for n-type (electron carriers).

Equations
Lorentz Force Magnitude
F = BQV sin θ
Force is maximum when velocity is perpendicular to B (θ=90°) and zero when parallel (θ=0°).
B = magnetic flux density (T)
Q = charge (C) = 1.6×10⁻¹⁹
V = velocity (m/s)
θ = angle between v and B
CRT Application
y = (eBL²)/(2mv²) · V_d
Screen deflection of an electron beam. Magnetic deflection coils use this principle.
Cyclotron Radius
r = mv / (|q|B)
Larger v → wider orbit. Stronger B → tighter orbit.

Equations
Force Between Wires
F/L = μ₀I₁I₂ / (2πd)
Force per unit length. Same-direction currents attract; opposite-direction currents repel.
μ₀ = 4π×10⁻⁷ H/m
I₁, I₂ = currents (A)
d = wire separation (m)
B Field Around Wire
B = μ₀I / (2πr)
The circular magnetic field generated by each wire exerts a force on the other. Defined the Ampere until 2019.
Right-Hand Rule
F = I L × B
Curl fingers in direction of B around wire 1; if current in wire 2 is parallel to that B-force direction, the wires attract.

Equations
Deflecting Torque
τ = NBIA
Torque on the coil. In a radial field B is always perpendicular to coil plane, so sin θ = 1 always.
N = number of turns
B = radial field strength (T)
I = current through coil (A)
A = coil area (m²)
Restoring Torque
τ_r = kθ
The phosphor bronze suspension provides a restoring couple proportional to deflection angle.
Equilibrium
θ = NBA·I / k
Deflection is directly proportional to current — making the galvanometer scale uniform (linear).
Current Sensitivity
S = θ/I = NBA/k
Increased by: more turns N, stronger B, larger area A, weaker spring k.
